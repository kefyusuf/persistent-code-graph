# M1.6 — Canonical API Bridge (provisional)

## Goal

Make orchestration a single reusable, tested API entry point without rewriting the parser, storage or verified query subsystems. This is an incremental consolidation of the existing prototype, **not** a claim of a production-grade semantic graph.

## Change

- `src/core.mjs`: sole implementation of `createFileFactsPipeline` and `createRealTreeSitterPipeline`.
- `src/index.mjs`: narrow public API `openCodeGraph({ checkoutRoot, indexRoot })` bound to the pinned real Tree-sitter provider, without an implicit or explicit temporary-parser fallback.
- `spikes/m1.5/src/pipeline.mjs`: backward-compatible re-export to the canonical implementation.
- Root `package.json`: Node.js 22+ private package with one published-style export (not published).
- `test/core.test.mjs`: offline public contract and refresh/query regression using a test-only provider in the internal factory.
- `test/real-grammar.test.mjs`: verifies the public API against actual pinned PHP, TypeScript and TSX grammar assets.
- The acceptance runner includes both new suites in the existing fail-closed gating.

## Boundaries and non-goals

The canonical core still delegates parsing, inventory, storage and verified query logic to their existing prototype modules; further migration must be gated. It does not yet resolve cross-file symbols, calls or inheritance. No CLI, MCP, agent memory, RAG, cloud, service, background watcher or new programming languages.

## Verified locally

The offline acceptance runner passed 125/125 tests. The new core's four tests passed. The real grammar entry-point test must run in CI using locked dependencies; do not report M1.6 as accepted until it passes on the proposed commit. The earlier CI success for M1.3/M1.5 is not evidence for this new entry point.

## Acceptance criteria

1. All legacy and new offline tests pass, with no skipped tests.
2. Real pinned grammar tests for M1.3/M1.5 and the M1.6 entry point pass on the same commit.
3. Existing spike imports continue to return the canonical implementation without behavior drift.
4. `main` remains unchanged pending PR review and successful gate evidence.

## Self-review

The new source entry point is deliberately narrow and the new tests cannot silently switch the public real-parser path to the temporary parser. Risk: production `src/` still imports experimental modules, and the parser package is installed under `spikes/m1.3`; this is transitional technical debt, not something to conceal. The next step should migrate one subsystem at a time without changing its observable contract.
