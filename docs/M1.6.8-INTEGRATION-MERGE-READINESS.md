## Technical scope audit

Verified by existing tests and the M1.6.7 review:
- Canonical runtime path uses `src/core.mjs`, `src/parser`, `src/storage`, `src/incremental`, and `src/query`; historical `spikes/` imports are compatibility/test paths.
- The index store refuses an index root physically inside the checkout, including an existing symlink redirect.
- Changed and newly introduced source languages are handled on refresh; unchanged compatible source facts are reused.
- Query reads are bounded and fail closed on detectable source/hash or index-head changes.

Known constraints that are **not resolved by this review**:
- There is no semantic cross-file call-target resolver; coverage remains partial.
- Symlink swaps or filesystem modifications **between** path verification and writes remain a time-of-check/time-of-use risk; the current static symlink guard is not a complete adversarial filesystem security boundary.
- Power-loss durability, Windows locking/rename behavior, and stale writer-lock recovery are not production-validated.
- Query freshness is point-in-time; each verified query re-hashes eligible working-tree contents twice.
- No benchmark of real token savings or representative large repositories has been accepted.

None of these unresolved constraints may be represented as a completed feature. They do not automatically prevent an **explicitly experimental** baseline, subject to the release-owner's risk acceptance.
