# M1.3 — Parser Compatibility Gate: Implementation and Evidence

**Project:** Persistent Code Graph (working title)
**Date:** 2026-11-01
**Status:** BLOCKED — real Tree-sitter grammar gate cannot pass in the current environment
**Dependencies:** M0.1, M0.2, M1.0, M1.1 and M1.2
**Scope:** Bounded parser-loader and file-local fact-contract spike only

## 1. Decision under test

Can independently versioned PHP, TypeScript and TSX grammar binaries be loaded with a single WASM Tree-sitter runtime and produce deterministic, source-backed, intentionally incomplete file-local facts without a language-specific assumption leaking into the graph core?

The goal of M1.3 is a **verified parser compatibility decision**, not a working repository index or production adapter. No language/runtime/storage selection is authorized until the integration gate passes.

## 2. Candidate and version pinning

The proof-of-concept declares exact candidate dependencies:

| Component | Declared version | Role |
|---|---|---|
| `web-tree-sitter` | `0.27.1` | Shared Tree-sitter WASM parser runtime |
| `tree-sitter-wasm` | `2.0.4` | Local grammar WASM assets, PHP + TypeScript + TSX |
| Node.js | >=22; local 22.16.0 | Executing the bounded test harness |

Evidence for the APIs and grammar identities: upstream `web-tree-sitter` README, `tree-sitter-wasm` package documentation, and official `tree-sitter-php` / `tree-sitter-typescript` node-type declarations.

**Constraint:** Because npm registry DNS resolution returned `EAI_AGAIN`, no package was installed, no lockfile was generated, no WASM file was loaded and no grammar checksum was measured. Candidate versions are not an adopted production dependency set. The loader is designed to reject missing/mismatched local dependencies and derive per-language cache identities from actual grammar SHA-256 only after installation.

## 3. Implemented minimal contract

`src/contract.mjs`:
- Classifies only `.php`, `.ts`/`.mts`/`.cts` and `.tsx` for the gate.
- Separates declarations from raw reference occurrences.
- Preserves TypeScript duplicate interfaces and function overload signature occurrences.
- Separates PHP trait-use syntax (`use_declaration`) from namespace imports (`namespace_use_declaration`) and `use_as_clause` adaptations.
- Does not synthesize target call edges (`relations: []`).
- Produces reproducible source-backed, within-input IDs with explicit parser identity.
- Verifies UTF-8 source slice equality for node byte ranges. A mismatch is a hard error rather than hidden mislocation.
- Reports parser recovery errors and missing tokens conservatively, with partial/failed coverage (not `supported`).

`src/runtime.mjs` is an isolated prototype loader:
- Imports exact-version local packages after a preflight version check.
- Uses locally installed PHP, TypeScript and TSX WASM binaries.
- Hashes the loaded grammar bytes and includes runtime/grammar/schema in cache identity.
- Never uses an online API, telemeter, model, database or network fetch during extraction.

**Important:** An offline test using constructed tree-shaped objects validates contract behavior only. It does not prove the real grammar yields these node types or AST shapes, nor that a particular WASM build is compatible.

## 5. Required evidence for a PASS

**M1.3 remains BLOCKED until ALL are true:**

1. A clean, network-independent test run is possible *after* a vetted, reproducible package installation; a real lockfile and exact dependency identities are captured.
2. The pinned WASM runtime successfully loads the PHP, TypeScript and TSX grammar binaries; their measured SHA-256 values are recorded.
3. All 12 real-grammar integration assertions pass, including duplicate declarations, aliases, trait-use separation, Unicode positions, parse recovery, TSX and TS overloads.
4. Unsupported or unresolved syntax remains explicitly incomplete, without invented resolved call edges.
5. An additional check confirms parser/grammar version changes invalidate only the affected file-level parse cache identity.
6. The exact test matrix and results are recorded for at least Windows and Linux, or the missing platform is explicitly registered as a release blocker.

If grammar tests reveal `node-types.json` or parser ABI incompatibilities, change the candidate or adapt extraction according to the observed CST, then rerun the complete suite. Do not advance on green mock/contract tests alone.

## 6. Deferred matters (not part of the gate)

Production language/runtime selection, a schema migration system, SQLite, persistent graph snapshots, Git worktrees, background watchers, CI event triggers, CLI graph querying, MCP integrations, token telemetry, user memory, embeddings, visualization and cloud service are all out of scope for this milestone.

The grammar-binary asset package may be too large for a minimal distribution. Bundle-size and platform portability tests are required before choosing a production shipping model. No production commitment is made by writing this harness.
